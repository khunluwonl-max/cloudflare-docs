You can now run more [Containers](/containers/) concurrently with significantly higher limits on memory, vCPU, and disk.

| Limit                                          | New Limit | Previous Limit |
| ---------------------------------------------- | --------- | -------------- |
| Memory for concurrent live Container instances | 6TiB      | 400GiB         |
| vCPU for concurrent live Container instances   | 1,500     | 100            |
| Disk for concurrent live Container instances   | 30TB      | 2TB            |

This 15x increase enables larger-scale workloads on Containers. You can now run over 20,000 instances of the `lite` instance type, over 6,000 instances of `basic`, over 1,500 instances of `standard-1`, or over 1,000 instances of `standard-2` concurrently.

See the [limits documentation](/containers/platform-details/limits/) for more details on the available instance types and limits.
